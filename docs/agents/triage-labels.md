# Triage labels

Use this mapping whenever an engineering skill refers to a canonical triage role.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate the issue |
| `needs-info` | `needs-info` | Waiting for information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and suitable for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

`ready-for-agent` describes specification readiness; a ticket's open blockers still gate when it can be started. Create missing labels during setup and preserve existing matching labels.
