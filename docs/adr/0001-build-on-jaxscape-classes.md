# ILG Toolkit builds on JAXScape's classes instead of wrapping them

The effective-resistance layer takes JAXScape's and Lineax's objects as they are. A conductance model carries a Lineax solver in `solver`, such as JAXScape's `GridMultigridSolver` (the default) or `CuDSSSolver`, with JAXScape's settings, in place of a configuration class that named solvers by string and rebuilt them. Each raster shape keeps a JAXScape `GridTopology` and, for an `AbstractReusableStateSolver`, the solver state that `ResistanceDistance.init` prepares and `reinit` refreshes. Saved models do not record the solver; the template passed to `load_model` supplies it. ILG Toolkit adds what JAXScape does not hold: the mean conductance of an edge, the checks of conductance surfaces and sampling units, and carrying solver states through training.

A configuration class restated JAXScape's solvers, their settings and their errors. Each JAXScape release then needed a matching change here, as raising JAXScape to 0.0.17 did, and a solver JAXScape adds stayed out of reach until ILG Toolkit named it. With JAXScape's objects, any Lineax solver works, tests pass a CPU double of cuDSS as the solver itself, and a JAXScape release reaches users through the pin alone.
